# SPR-007 — Batch HTML publishing

Publish immediate regular `.md` children (extension case-insensitive) using one
runtime and the existing safe, atomic per-document publisher. Subdirectories
and other extensions are ignored. Symbolic source files follow existing single
document behavior. Input ordering is deterministic by case-folded name then name.

`bgdxpublisher publish-batch SOURCE_DIR --output-dir OUTPUT_DIR`
supports `--overwrite`, `--config`, `--lang`, `--theme`, and `--toc`.
Each document title defaults to its filename stem. There is no shared title option.
Output directories and missing parents are created. An output-directory symlink
is rejected. Existing destination protections are unchanged.

Missing/non-directory input, no matching files, invalid options, destination
creation failures, and case-insensitive destination collisions fail before any
documents are published. An empty batch returns 1, not a misleading success.
Expected individual publication errors are reported and remaining files continue.
Reports list each success/failure plus counts. Exit 0 means every item and runtime
cleanup succeeded; exit 1 means a domain, item, or cleanup error; invalid CLI
arguments return 2. This is per-document atomicity, not a batch transaction.

Acceptance: deterministic selection, Unicode/BOM, metadata/themes/TOC propagation,
overwrite refusal and explicit replacement, partial failure continuation,
preflight errors, startup and cleanup failures, installed-wheel CI on Windows
and Linux with Python 3.13/3.14, coverage at least 99%.
