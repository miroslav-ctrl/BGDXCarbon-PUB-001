# SPR-005 — Built-in HTML Themes

`publish --theme light|dark` selects a fixed embedded CSS palette. Default `light`
preserves existing text, link, code and quote colors with explicit white background.
`dark` sets dark page/code backgrounds, light text, blue links and a gray quote border.
Neither theme adds external assets or changes the Markdown body, title or language.

PublishRequest adds `theme="light"`; HtmlRenderer validates it before parsing.
CLI invalid choices exit 2 with the supported choices. Invalid direct-service
requests raise PublishingError before output staging; existing output and source
are preserved. Output atomicity and explicit overwrite remain unchanged.

```sh
bgdxpublisher publish document.md --output dark.html --theme dark --title "Izveštaj" --lang sr-Latn
```

User CSS, templates, PDF/DOCX, batch processing and UI are outside scope.
