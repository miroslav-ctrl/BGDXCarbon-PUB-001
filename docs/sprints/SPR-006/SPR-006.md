# SPR-006 — Optional HTML Table of Contents

`publish --toc` adds a navigation block before the document body. It indexes all
parsed Markdown headings h1–h6 in source order, including Setext headings, with
indentation by heading level. Headings inside fenced code are excluded.

Labels use plain inline text with formatting/link destinations stripped and HTML
characters escaped. IDs use NFC-normalized, case-folded letters/digits separated
by hyphens, prefixed `section-`. Collisions receive numeric suffixes starting at 2,
checked against all previously generated IDs. Fragment URLs are percent-encoded.
Empty headings use the label `Untitled section`; punctuation-only IDs use `heading`.
The nav caption is `Contents`, tagged English; heading links inherit document lang.

Without --toc, output is unchanged, including absent heading IDs and TOC CSS. With
--toc and no headings, output is also unchanged. Styling uses the selected palette.
Title, document language, safety rules, atomicity and overwrite policy are preserved.

```sh
bgdxpublisher publish document.md --output document.html --toc --theme dark --lang sr-Latn
```

PDF/DOCX, templates, batch publishing and UI remain outside scope.
