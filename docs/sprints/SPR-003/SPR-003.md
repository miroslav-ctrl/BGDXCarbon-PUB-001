# SPR-003 – Document Publishing Foundation

## Goal

Publish a local UTF-8 Markdown document as a standalone HTML document through
the existing CLI, runtime, configuration, logging and service registry.

```sh
bgdxpublisher publish document.md --output document.html
bgdxpublisher publish document.md --output document.html --overwrite
bgdxpublisher publish document.md --output document.html --config custom.yaml
```

Headings, paragraphs, ordered/unordered lists, emphasis, links, block quotes
and fenced code are supported. Styles are embedded; no network request is made
during publishing. Images become alternative text. Raw HTML is escaped and
unsafe links are left as text. No remote resources are loaded by the output.

Output parents must already exist. No implicit directory creation or file
replacement occurs. Publishing never modifies the input. Existing output needs
`--overwrite`. Equal paths, hard-link aliases, symbolic output links and
nonregular files are refused. Exit codes: 0 success, 1 expected operational
error, 2 invalid arguments. A cleanup failure after publication returns 1 and
reports the cleanup problem; the completed output remains available.

PDF/DOCX, user templates, batch publishing, plugins, GUI/web, authentication,
cloud storage and hosting remain outside this sprint.
