## Goal and scope

Provide deterministic non-recursive directory-to-DOCX publication with immutable
per-item terminal executions, safe batch preflight errors and independent commits.
Reuse existing single-document DOCX pipeline; preserve all commands/direct APIs.

Proposed new package docx_batch_pipeline, runtime registration, tests, installed
wheel example, ninth independent coverage gate and documentation. No new CLI,
batch PDF, HTML index changes, DOCX index/manifest, title override, theme/TOC,
templates, renderer/writer/engine changes, parent batch job, retry/storage/queues,
parallelism, transaction/rollback, dependency/version change or release/tag.
Existing eight gates and total >=99% remain. main outside scope.
