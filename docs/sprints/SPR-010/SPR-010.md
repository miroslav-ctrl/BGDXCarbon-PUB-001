# SPR-010 — PDF publishing foundation

User-approved sequence: DOCX, then PDF. This branch is based on the ready DOCX
PR #16 (feature/spr-009-docx), which has not yet merged into develop. The PDF PR
targets that feature branch to keep its diff scoped to this sprint. Merge the
DOCX dependency first and retarget/rebase the PDF PR onto develop afterward.

Command: `publish-pdf SOURCE --output OUTPUT.pdf [--overwrite] [--config PATH]
[--title TEXT] [--lang TAG]`. Existing HTML/DOCX commands retain their defaults.
No extension-based format guessing is introduced.

ReportLab renders safe CommonMark tokens directly to PDF; no browser, Office or
LibreOffice executable is required. The package includes five unmodified DejaVu
2.37 fonts and their upstream license. The official font archive SHA-256 was
verified before inclusion. PDF output embeds font subsets and Unicode maps;
Serbian Latin/Cyrillic text is selectable. Title and language are metadata.
Unsupported glyphs/XML controls fail with a code-point diagnostic.

Print layout: A4 portrait, 2.5 cm margins, black heading hierarchy, 11-point body
text, 10-point monospace code, automatic pagination and heading keep-with-next.
CommonMark headings 1–6, paragraphs, emphasis, nested lists, independent ordered
list starting numbers, quotations and inline/fenced/indented code are supported.
Long words and code lines wrap. HTTP(S)/mailto links are PDF URI annotations;
Wide numeric markers reserve enough space before item text; excessive nesting
fails clearly when it cannot leave readable page width.
relative and fragment destinations remain text. Images become plain alternative
text even for rejected destinations; raw HTML is literal text. No assets are
fetched and no script is executed.

Input accepts UTF-8 with optional BOM; output must end in `.pdf`, with an existing
parent directory. Source/output alias checks and the existing atomic binary
writer protect source/previous output and retain no-overwrite race protection
and POSIX permission behavior. Runtime closes on expected success/failure.
Exit codes remain 0/1/2. Expected ReportLab layout/font failures become domain
errors. Version stays at 1.0.0 in development until separate release preparation;
published v1.0.0 remains immutable.

Out of scope: PDF batch/index, templates, embedded images, TOC/bookmarks,
PDF/UA/PDF-A claims, signatures/encryption, GUI and hosting.

Acceptance: >=99% total coverage, typed/format checks, actual PDF parsing of
text/metadata/links/embedded fonts, long-document tests, installed-wheel checks
on Windows/Linux Python 3.13/3.14, and complete rendered-page visual inspection.
