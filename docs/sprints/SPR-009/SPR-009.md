# SPR-009 — DOCX publishing foundation

User-approved order: DOCX before PDF. This sprint adds `publish-docx SOURCE
--output OUTPUT.docx [--overwrite] [--config PATH] [--title TEXT] [--lang TAG]`.
Existing `publish` and `publish-batch` remain HTML commands with their existing
defaults. There is no extension-based format guessing.

DOCX output uses editable Word paragraph/run styles, A4 portrait, 2.5 cm margins,
Arial body text and black headings. CommonMark headings 1–6, paragraphs, emphasis,
inline/fenced/indented code, quotations and nested ordered/bullet lists are
supported. Each list has independent numbering, including explicit starting
numbers. HTTP/HTTPS/mailto links retain inline formatting and external targets.
Relative and fragment targets are plain labels because no bookmark or portable
file-link mapping is defined. Images preserve plain alternative text, including
rejected destinations. Raw HTML is text. No images, macros or external resources
are loaded during publishing. Language metadata uses the existing validation
subset and sets default Word proofing language. Title is metadata only.

Input accepts UTF-8 with optional BOM. XML-incompatible characters fail cleanly;
CommonMark replaces NUL with the Unicode replacement character. The source stays
unchanged. Expected errors return 1, parser errors return 2, success returns 0.
Output must have `.docx` extension and an existing parent. The same atomic binary
writer serves HTML and DOCX, preserving no-overwrite race protection and POSIX
permissions. Runtime closes after publication or expected failures.

`python-docx>=1.2,<2` is a runtime dependency. This development sprint keeps the
published 1.0.0 version number until a separate release increment is prepared;
the existing immutable GitHub release is unchanged.

Outside scope: DOCX batch/index, custom templates, tables (not enabled by the
CommonMark parser), embedded images, dynamic contents, PDF, GUI and hosting.

Acceptance requires typed/format checks, >=99% total coverage, Windows/Linux
Python 3.13/3.14 CI, installed-wheel smoke checks and a rendered sample review.
