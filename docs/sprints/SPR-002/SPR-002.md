# SPR-002 – Enterprise CLI & Diagnostics

## Goal

Provide a standard-library CLI for version reporting, runtime diagnostics,
configuration validation, and runtime status without bypassing the approved
SPR-001 application and service contracts.

## Commands

- `bgdxpublisher --help`
- `bgdxpublisher version`
- `bgdxpublisher doctor`
- `bgdxpublisher config validate`
- `bgdxpublisher runtime status`

Commands that initialize the runtime accept an optional `--config PATH`;
configuration validation also uses the existing `ConfigurationService`.

## Diagnostics

The doctor checks the Python version, configuration, logging initialization,
service registry, runtime lifecycle, and workspace accessibility. A mandatory
failure returns exit code 1. Optional workspace warnings do not fail the
command.

## Scope

Document publishing, templates, plugins, GUI, web/API, authentication, storage,
and telemetry remain out of scope.
