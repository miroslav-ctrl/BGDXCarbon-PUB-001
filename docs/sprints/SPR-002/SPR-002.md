# SPR-002 – Enterprise CLI & Diagnostics

## Goal

Provide enterprise command-line access to the SPR-001 application runtime and
structured diagnostic checks without bypassing its configuration, logging,
service registry, or lifecycle contracts.

## Commands

- `bgdxpublisher --help` displays the command tree.
- `bgdxpublisher version` reports application, Python, and environment versions.
- `bgdxpublisher doctor` runs the Python, configuration, logging, service
  registry, runtime, and workspace checks.
- `bgdxpublisher config validate` validates settings through
  `PublisherApplication` and the existing `ConfigurationService`.
- `bgdxpublisher runtime status` initializes the existing runtime and reports
  its metadata and lifecycle state.

Commands that load configuration accept `--config PATH`; the default is
`configs/default.yaml`. Install the package to expose the `bgdxpublisher`
console script. No new CLI dependency is required.

## Diagnostics

Each check returns a typed `DiagnosticResult` with a `PASS`, `WARNING`, or
`FAIL` status. `DiagnosticService` executes checks and aggregates a
`DiagnosticReport`; presentation remains in the CLI. Doctor returns 1 only
when a mandatory check fails. Warnings do not change the successful exit code.

## Scope

This sprint adds CLI and diagnostics functionality only. Document processing,
publishing engines, plugins, GUI/API, authentication, storage, and telemetry
remain out of scope.
