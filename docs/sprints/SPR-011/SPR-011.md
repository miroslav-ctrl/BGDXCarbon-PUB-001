# SPR-011 — Publisher Job Execution Orchestration

Status: planned; implementation issue [#22](https://github.com/miroslav-ctrl/BGDXCarbon-PUB-001/issues/22).
Baseline: develop d4d31435e641a76dd1946d2ee255df2d523c406f after SPR-003/004 acceptance closure.
SPR-001 through SPR-010 are already allocated.

## Goal

Connect the existing immutable publisher jobs and deterministic pipeline engine through one synchronous application service. Callers submit a QUEUED job and a value, and receive an explicit completed job or a typed failure carrying the final FAILED job.

## Scope

Add bgdxpublisher.orchestration with JobExecutionService, immutable execution result/history envelopes and typed errors. Inject JobService and PipelineEngine. Allocate a fresh PipelineContext per call and register the coordinator in PublisherApplication using its existing logger. Provide one Python API example and an installed-wheel smoke check.

QUEUED is a lifecycle state, not a durable queue. Existing HTML, DOCX, PDF and batch services retain their interfaces and are not migrated in this sprint.

## Exclusions

No persistent queue, worker, concurrency, retry, cancellation, database, new CLI, format adapter migration, hosting or release/version change. No modification of main.
