# Bundled PDF fonts

Unmodified DejaVu Fonts 2.37: Sans regular, bold, oblique, bold-oblique and Sans
Mono regular. The font license and attribution are preserved in LICENSE.txt.

Upstream: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

Archive: `dejavu-fonts-ttf-2.37.zip`
SHA-256: `7576310b219e04159d35ff61dd4a4ec4cdba4f35c00e002a136f00e96a908b0a`
The downloaded archive was verified against the published upstream checksum.
Only the listed TTF files and the complete upstream license are redistributed.

PDF output embeds font subsets. These assets are package data, so publication
does not depend on machine fonts or download resources at runtime.
